Command Interface
Lesson

Write code to command your survivors. Each command expresses intent — the simulation validates and executes it.

survivor.gather("wood", 10);

Your code runs in an isolated Worker. It can only request actions; each command costs 1 strategy point, which comes back over time. Survivors keep working on a command until it stops by itself: storage full, nothing left to gather, or too tired.

survivor.gather("wood", 20); // trips of 20, until done
survivor.gather("wood", 20, 60); // stop after 60 wood

A new program replaces what the survivor was doing; its commands run top to bottom. Call survivor.queue() first to add to the end instead.

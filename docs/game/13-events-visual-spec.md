- Zombie Nest Raid: raid marker, expedition/group state, nest state, combat effects and completion/failure presentation.

- Scavenge Supply: target-site marker, survivor expedition state, search/loot interaction and recovery presentation.

- Resource Expedition: target resource marker, worker group state and gathered-resource presentation.

- Defense Event: alert state, threat indicator, survivor guard/attack states and building damage state.

- Event visuals are projections of event state; they never determine event success or failure.
